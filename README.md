# いまのバス遅れ

バスの車内でスマホ(主に iPhone の Safari)から開くと，**いま乗っている都営バス**を現在地から推定して，
**定刻より何分遅れているか**を表示するWebアプリです．

**アプリ: https://my-bus-delay.stachibana02.workers.dev**

> **このアプリは都営バス(東京都交通局)の公式サービスではありません．**
> 表示は公開データからの推定で，必ずしも正確・完全なものとは限りません．
> **運転中は使用しないでください．**

## 使い方

1. 上のURLを iPhone の Safari で開く(ホーム画面に追加すると，アプリのように使えます)．
2. バスに乗ったら「現在地で乗っているバスを探す」を押し，位置情報の利用を許可する．
3. バスが走り出して1〜2分すると，乗っているバスと遅れが表示されます．
   候補が複数あるときは，一覧から選べます．「バス停から選ぶ」こともできます．

画面を開いたままにしてください(ロック中は位置が更新されません)．

## プライバシー

- 位置情報は**端末の中だけ**で使い，サーバへ送信・保存しません．
- 文字の表示に Google Fonts を使っています．

## データの出典

- 東京都交通局・公共交通オープンデータ協議会(CC BY 4.0)
  - 東京都交通局 バス関連情報(GTFS/GTFS-JP): https://ckan.odpt.org/dataset/b_bus_gtfs_jp-toei
  - 東京都交通局 バス関連リアルタイム情報(GTFS-RT): https://ckan.odpt.org/dataset/b_bus_gtfs_rt-toei
- 本アプリが利用する公共交通データは，公共交通オープンデータセンター(https://www.odpt.org/)において
  提供されるものを加工したものです(時刻表と車両の位置から遅れを推定しています)．
